# Говорилка

Транскрибация созвонов в реальном времени. Работает на вашем компьютере, звук никуда не уходит.

Пишет сразу два источника:

- **Я** — ваш микрофон;
- **Собеседник** — всё, что играет в колонках или наушниках (Zoom, Teams, Telemost, браузер).

Видео не пишется. Звук на диск тоже не сохраняется, только текст.

Ещё Говорилка расшифровывает готовые файлы: **аудио** (mp3, wav, m4a, ogg, opus, flac, aac, wma) и **видео** (mp4, mkv, mov, webm, avi, wmv). Из видео берётся только звук. Длина не ограничена: файл читается потоком, двухчасовая запись Zoom не съест память.

Распознаёт модель **GigaAM v3** от Сбера (та же, что в Handy). Она сама ставит знаки препинания и заглавные буквы. Работает на процессоре: 8 секунд речи распознаёт примерно за 0.1 секунды. Видеокарта не нужна.

Работает на **Windows 10/11** и на Mac: **Apple Silicon** (M1–M4, macOS 14+) и **Intel** (macOS 13+).

## Установка

**Проще всего — одной командой.** Так не будет предупреждений «неизвестный издатель» и «не удаётся проверить
разработчика»: скрипт сам скачивает последний релиз с GitHub и сверяет его контрольную сумму.

Windows (PowerShell, программа ляжет в `%LOCALAPPDATA%\Programs\Govorilka`, ярлык — в «Пуск»):

```powershell
irm https://raw.githubusercontent.com/fedintsevqq/govorilka/main/install.ps1 | iex
```

Mac (Терминал, программа ляжет в «Программы»):

```bash
curl -fsSL https://raw.githubusercontent.com/fedintsevqq/govorilka/main/install.sh | bash
```

Mac через Homebrew:

```bash
brew install --cask fedintsevqq/tap/govorilka
```

**Или вручную.** Сайт программы: https://fedintsevqq.github.io/govorilka/. Скачайте файл для своей системы со страницы [Releases](https://github.com/fedintsevqq/govorilka/releases/latest):

- Windows — `Govorilka-…-windows-x64.exe`, запускается без установки;
- Mac на Apple Silicon (M1–M4) — `Govorilka-…-macos-apple-silicon.dmg`;
- Mac на Intel — `Govorilka-…-macos-intel.dmg`.

На Mac откройте `.dmg` и перетащите Говорилку в «Программы». Какой у вас чип, видно в меню  → «Об этом Mac».

При первом запуске приложение скачает модели (около 880 МБ: распознавание речи, детектор речи и модель голосов) и покажет процент. Дальше интернет не нужен.

### Первый запуск на Mac

Приложение не подписано сертификатом Apple, и в первый раз macOS его не откроет. Закройте предупреждение и откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Или в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/Govorilka.app
```

При первой записи macOS спросит два доступа: к микрофону и к «записи экрана и системного звука». Нужны оба. Через второй macOS отдаёт звук собеседников, а видео Говорилка не пишет. После разрешения перезапустите приложение.

### Первый запуск на Windows

SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

1. Впишите тему созвона вверху (попадёт в имя файла и заголовок). Можно не вписывать.
2. Нажмите большую кнопку записи. При первом запуске Говорилка скачает модели и покажет процент.
3. Текст появляется справа по ходу разговора. Серым курсивом с мигающим курсором — фраза, которую ещё договаривают. Она уточнится, когда человек сделает паузу.
4. Во время записи доступны **«Пауза»** и **«Отметка»**: отметка ★ ставится на текущий момент («тут обсуждали баг») и остаётся в транскрипте, а Claude Code увидит её при разборе.
5. Нажмите кнопку ещё раз — запись остановится, файл сохранится.

### Окно, значок в трее и круговое меню

Интерфейс сделан на Qt: тёмная и светлая тема (по системе или вручную), плавное движение с уважением к настройке «Уменьшить движение», клавиатурное управление и подписи для программ экранного чтения.

**Значок в трее (Windows) и в строке меню (Mac).** Закрытие окна крестиком не завершает Говорилку, а убирает её в трей: запись и горячая клавиша продолжают работать. Значок меняется по состоянию: на Windows — знак приложения, при записи красный, на паузе янтарный; на Mac в ожидании — монохромный микрофон под цвет строки меню, при записи красный диск. В меню значка: начать или остановить запись, пауза, отметка, отправить нейросети, открыть транскрипт, показать окно, настройки, выйти. Выйти совсем можно только отсюда.

**Круговое меню по горячей клавише.** Зажмите комбинацию на полсекунды: у курсора появится меню из шести секторов. Выбор идёт **по направлению**, попадать в иконку не нужно:

- зажали клавишу, повели мышь в сторону сектора и отпустили, действие выполнится (жест одним движением);
- либо отпустите клавишу и просто кликните по сектору;
- либо нажмите цифру 1–6, стрелки и Enter. Esc или клик мимо закрывают меню.

Во время записи сектора такие: Стоп, Пауза/Продолжить, Отметка, Отправить нейросети, Транскрипт, Окно. В ожидании: Запись, Отправить нейросети, Транскрипт, Настройки, Окно. В центре видно состояние и время записи. В настройках можно выбрать, что делает комбинация: открывать меню или сразу начинать и останавливать запись.

**Плашка записи.** Когда главное окно скрыто, поверх экрана висит маленькая плашка «● Запись 12:34» с живым уровнем звука. Она не отнимает фокус у вашей программы и пропускает клики сквозь себя.

### Тихая запись по горячей клавише

Говорилку можно держать свёрнутой и запускать запись одной комбинацией клавиш. Окно при этом не открывается, а поверх экрана на секунду появляется плашка «● Запись 00:12». Нажали снова, и запись остановилась: транскрипт сохранён в папку **Загрузки/Govorilka** (в настройках её можно поменять).

| | По умолчанию |
|---|---|
| Windows | **Ctrl + Shift** |
| Mac | **Option + Command** |

Для комбинации из одних модификаторов её нужно **удерживать полсекунды**. Так обычные сочетания вроде Ctrl+Shift+Esc или Option+Command+Esc ничего не запускают. Если задать комбинацию с буквой (например, Ctrl+Shift+R), достаточно просто нажать.

Комбинацию меняют в «Настройках»: кнопка «Изменить…», нажать нужные клавиши и отпустить. Там же включается **автозапуск при входе в систему**: Говорилка стартует свёрнутой и ждёт горячую клавишу. Закрытие окна (крестик, Cmd+Q) завершает программу целиком, поэтому для работы в фоне окно сворачивайте.

Если запущена ещё одна копия Говорилки, новая не откроется, а покажет окно первой. **При обновлении с версии 0.2.1 и старше** закройте старую Говорилку: она не видит новую, и горячая клавиша сработала бы в обеих. Новая версия заметит старую и предупредит. Автозапуск после обновления сам переключается на новый файл.

Про раскладку: в Windows сочетанием Ctrl+Shift иногда переключают язык ввода. Если у вас так, при записи по Ctrl+Shift язык тоже переключится. Тогда задайте другую комбинацию, например Ctrl+Shift+R. Посмотреть: «Параметры → Время и язык → Ввод → Дополнительные параметры клавиатуры → Сочетания клавиш для языка ввода».

На Mac для горячей клавиши нужно разрешение **«Мониторинг ввода»**: без него macOS не отдаёт программе состояние клавиш. Говорилка проверяет это при запуске и в настройках, сама показывает системный запрос и кнопку «Открыть» к нужному разделу. После включения перезапустите приложение. В настройках под комбинацией видно, какие клавиши Говорилка видит прямо сейчас: если там всегда «ничего», разрешения нет.

### Расшифровка файла

Кнопка **«Открыть файл…»**: выберите запись созвона, лекцию или видео. Рядом появится полоса прогресса, текст идёт по мере расшифровки. Кнопка превращается в «Отменить расшифровку»: то, что уже готово, сохранится. На вашем процессоре час записи расшифровывается за несколько минут. Результат тот же `.md`, его так же можно отправить в Claude Code.

### Кто говорит

Микрофон — это **«Я»**. Звук компьютера Говорилка делит по голосам: **«Собеседник 1»**, **«Собеседник 2»** и так далее, у каждого свой цвет. В файлах голоса называются **«Спикер 1»**, **«Спикер 2»**. Если голоса путаются, снимите галочку «Различать голоса»: тогда все собеседники будут одним «Собеседником».

**Как голоса различаются.** На каждой новой фразе Говорилка заново группирует все фразы созвона сразу (так же, как после остановки), а не сравнивает по очереди. Поэтому первые фразы человека, пока голос ещё не «выучен», не превращаются в лишних собеседников. Номера держатся стабильными: «Собеседник 2» остаётся «Собеседником 2». Если пересчёт поправил подпись у прошлой фразы, она меняется в ленте и в файле, а имя едет за человеком. Короткие реплики («да», «угу», от 0,6 секунды) идут за ближайшим голосом. Группа короче трёх секунд, похожая на другой голос, к нему присоединяется. После остановки записи проходит последний полный пересчёт. Так же работает расшифровка файлов.

**Имена.** Нажмите на имя в ленте и впишите, кто это: «Аня». Имя встанет во все реплики этого человека, и новые его реплики сразу придут с именем. Оно переживёт пересчёт голосов.

**Имена из разговора.** Если человек сказал «меня зовут Аня», «это Олег, на связи» или «с вами Ира», Говорилка подпишет его сама. Обращение («Ира, что скажешь?») и «спасибо, Дима» считаются, когда повторились. Имя берётся только из списка настоящих имён, поэтому «это плохо» именем не станет. Подписанные вами имена она никогда не перебивает, а имена из разговора не попадают в память голосов: попали бы только после вашей правки.

**Память голосов (по желанию, выключена по умолчанию).** Если включить «Запоминать голоса знакомых», то подписанный вами человек будет узнаваться в следующих созвонах сам. Это биометрические данные, поэтому: хранится только числовой отпечаток голоса (256 чисел), а не запись; файл `voices.json` лежит локально в папке данных и никуда не отправляется; в настройках видно, сколько голосов запомнено, и есть кнопка «Забыть всех». Знакомого узнаём строже, чем «того же человека в этом созвоне», и одно имя двум людям в одном созвоне не даём.

Ограничения: голос определяется по фразе длиннее секунды. Два очень похожих голоса (например, два мужских голоса через плохой микрофон) могут слиться в один. Если двое говорят одновременно, фраза получит подпись преобладающего голоса.

### Смена наушников и микрофона

Подключили Bluetooth-наушники, выдернули USB-микрофон, выбрали другой вывод звука посреди созвона: запись сама переключится на новое устройство (проверка раз в 2 секунды), а в строке состояния появится сообщение. Транскрипт при этом не прерывается. Если устройство пропало совсем, Говорилка пробует переподключиться, пока оно не вернётся.

### Где лежат транскрипты

Папка **Загрузки/Govorilka**, файл вида `2026-10-23_14-05_Планёрка_QA.md`. Файл переписывается после каждой фразы, так что даже при сбое текст не потеряется. Папку можно поменять в **«Настройках»**.

Ещё есть **«Сохранить как…»** (`.md` или `.txt`) и **«Копировать»** в буфер обмена.

### Отправка в нейросеть

Кнопка в левой панели отправляет разговор в нейросеть по вашему выбору. Под кнопкой лента: **Копировать, ChatGPT, Claude, Claude Code, Gemini, DeepSeek, GigaChat, Алиса**. Нажали на нужную, и кнопка отправляет туда. Выбор можно сменить и в настройках. По умолчанию стоит «Скопировать для нейросети»: запрос и весь разговор кладутся в буфер обмена, вставить можно куда угодно.

**Что происходит:**

- **Приложение ChatGPT или Claude установлено** (Windows и Mac): разговор открывается в нём. Claude: короткий разговор сразу в поле ввода, длинный вставляется сам. ChatGPT: приложение запускается, разговор вставляется в поле ввода сам. Пункт «Где открывать» в настройках: «в приложении, если оно установлено» или «всегда в браузере».
- **Приложения нет:** открывается сайт в браузере, разговор вставляется сам.
- **Вставка** ждёт, пока окно чата окажется впереди, ставит курсор в поле ввода и нажимает Ctrl+V (⌘V). Если вы ещё не вошли в аккаунт, она ждёт до 5 минут, а после входа вставляет. Enter Говорилка не нажимает никогда: проверьте текст и отправьте сами. Не вставилось, нажмите Ctrl+V: разговор в буфере.
- **Mac:** для вставки нужно разрешение «Универсальный доступ» (Настройки → Конфиденциальность и безопасность). Без него разговор остаётся в буфере. В чатах, которые не ставят курсор в поле сами, на Mac может понадобиться один клик в поле.
- **Claude Code** открывается в приложении Claude (вкладка Code) с папкой транскриптов, если оно установлено, иначе в окне терминала: Windows Terminal, если есть, иначе PowerShell; на Mac в Терминале. Приложение попросит подтвердить папку.
- Где установлено приложение, неважно: оно ищется через систему (реестр и меню «Пуск» на Windows, Spotlight на Mac), на любом диске.

**Защита от блокировки.** ChatGPT, Claude, Gemini и Claude Code не работают из некоторых стран, а вход оттуда без VPN может закончиться блокировкой аккаунта. Перед тем как открыть что-то из них, Говорилка анонимно (без аккаунта и без текста) спрашивает у самого сервиса, из какой страны он вас видит. Из страны, где сервис не работает, или если он не отвечает, она ничего не открывает и не отправляет: разговор остаётся в буфере, а подсказка предлагает включить VPN или выбрать GigaChat, Алису или DeepSeek. Им VPN не нужен, проверка для них не выполняется.

Текст запроса меняется в **«Настройках»** ({file} в нём означает транскрипт). Для Claude Code там же можно указать папку, в которой его запускать.

Кнопка работает и во время созвона: Claude Code перечитывает дописывающийся файл.

При первом запуске macOS спросит, можно ли Говорилке управлять Терминалом: разрешите.

Говорилка находит Claude Code сама. Порядок поиска: установленный отдельно (`~/.local/bin`, Homebrew, PATH), затем копия, встроенная в приложение **Claude Desktop** (Windows: `%APPDATA%\Claude\claude-code`, Mac: `~/Library/Application Support/Claude/claude-code`). Из нескольких версий берётся самая свежая. Если у вас стоит Claude Desktop, ничего ставить не нужно.

Если Claude Code не найден, поставьте его отдельно. Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Mac (Терминал):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Если CLI не найден, Говорилка скопирует запрос с путём к файлу в буфер обмена.

### Наушники и эхо

Без наушников микрофон слышит колонки, и слова собеседника попали бы в транскрипт ещё раз, как ваши. Галочка **«Убирать эхо колонок»** включает эхоподавление WebRTC: звук колонок служит образцом, и Говорилка вычитает его из микрофона. На проверке с колонками эхо падало на 16–26 дБ, собеседник в микрофоне переставал распознаваться совсем, а ваш голос терял около 2 дБ и распознавался как раньше. Поверх этого работает прежний фильтр, который убирает совпадающие по словам повторы (фразы короче трёх слов он не трогает, чтобы не съедать ваши «да» и «ок»). В наушниках галочку можно выключить.

## Диктовка в любое поле

Зажмите **Ctrl + Alt** (на Mac **Control + Option**) и говорите. Отпустите — текст появится там, где стоит курсор: в браузере,
Claude, ChatGPT, Discord, Telegram, Word, где угодно. Пока вы говорите, внизу экрана видна маленькая плашка со знаком
Говорилки и полосками голоса, потом кольцо «Распознаю…».

- Фразы распознаются по ходу, поэтому даже после минуты диктовки текст появляется почти сразу. Дольше двух минут
  диктовка не пишет: зажатую по ошибке клавишу не записываем вечно.
- Вставка идёт через буфер обмена, а прежнее его содержимое сразу возвращается на место.
- Если, держа комбинацию, вы нажали букву (например, Ctrl+Alt+C), это сочетание, а не диктовка: ничего не вставится.
- Комбинация и выключатель — в настройках, раздел «Диктовка». У записи и диктовки комбинации должны быть разными.
- **Mac:** чтобы текст вставлялся сам, нужен «Универсальный доступ» для Говорилки. Без него текст окажется в буфере,
  нажмите ⌘V. Для самой комбинации нужен «Мониторинг ввода», как и для основной горячей клавиши.

## Подсказки в звонке

Отдельная функция, выключена по умолчанию. Включите кнопку **«Подсказки»** в пульте записи или в настройках, раздел
«Подсказки в звонке». Во время записи Говорилка слышит вопросы собеседника («Как вы организуете регресс?», «Расскажите
про опыт…») и сразу показывает в отдельном окне ответ, который можно сказать вслух. Если вопрос не распознался, кнопка
«Ответить» отвечает на последнюю фразу собеседника.

- **Модель на компьютере** — та же, что пишет итоги (Qwen3 4B по умолчанию). Разговор не покидает компьютер. На мощном
  компьютере первые слова ответа через секунду, весь ответ за 5–7 секунд. Памяти нужно примерно на 1,5 ГБ больше, чем
  для итогов: модель работает вместе с распознаванием.
- **Через API** по вашему ключу: OpenAI, DeepSeek, OpenRouter, Claude или любой сервис, совместимый с OpenAI. Быстрее и
  умнее, но вопрос собеседника и последние реплики уходят провайдеру. Ключ хранится в «Диспетчере учётных данных»
  Windows или «Связке ключей» Mac, а не в файле настроек.
- В поле «Что нейросети знать о вас и теме» напишите свою роль, опыт и о чём разговор: без этого ответы общие.
- **Окно не видно при демонстрации экрана.** На Windows 10 версии 2004 и новее оно исключено из захвата экрана: в Zoom,
  Teams, Телемосте и записи экрана его нет, а вы его видите. На старой Windows вместо окна будет чёрный прямоугольник.
  На Mac начиная с macOS 15 часть программ для звонков может окно всё же показать: проверьте на своей, начав
  демонстрацию. Фото экрана телефоном это не остановит.

Подсказки на собеседованиях и экзаменах обычно запрещены правилами. Решение и ответственность — за тем, кто пользуется.

## Итоги созвона

Рядом с разговором вкладка **«Итоги»**: кратко о чём говорили, решения, задачи с ответственными и сроками, открытые
вопросы. Считает языковая модель на вашем компьютере: разговор никуда не уходит, интернет нужен только один раз, чтобы
скачать движок (llama.cpp, около 20 МБ) и модель. Итоги сохраняются в начало файла транскрипта разделом «Итоги».

Модель выбирается в настройках, раздел «Итоги»:

| Модель | Размер | Памяти нужно | Какая |
|---|---|---|---|
| Qwen3 4B (по умолчанию) | 2,3 ГБ | от 8 ГБ, удобно от 12 ГБ | баланс качества и скорости |
| Qwen2.5 1.5B | 1 ГБ | от 6 ГБ, удобно от 8 ГБ | самая лёгкая, итоги проще |
| YandexGPT 5 Lite 8B | 4,6 ГБ | от 12 ГБ, удобно от 16 ГБ | лучше всех пишет по-русски |

Говорилка смотрит, сколько памяти у компьютера. Модель, которой её не хватит, выбрать нельзя: карточка прямо пишет
«на этом компьютере 4 ГБ памяти, а модели нужно не меньше 8 ГБ». Если памяти впритык, предупреждает, что будет медленно.
Пока считаются итоги, модели распознавания выгружаются, чтобы освободить память.

Загрузка продолжается с места обрыва: если связь пропала, нажмите ещё раз. Файлы движка и модели сверяются по SHA-256.

## Все возможности и «Что нового»

Кнопка «Как пользоваться» в настройках открывает список всего, что умеет Говорилка. После обновления окно «Что нового в 0.3.3»
открывается само и показывает только то, что появилось с прошлого раза; новое в общем списке помечено «Новое». Список лежит
в `govorilka/features.py`: новая возможность — одна запись, и она попадёт в оба окна.

**Запуск при входе в систему.** При первой установке Говорилка сама включает автозапуск, чтобы горячая клавиша работала сразу.
Выключить можно в настройках. Если вы обновляетесь, автозапуск не трогается.

## Обновления

Раз в сутки (и через несколько секунд после запуска) Говорилка анонимно спрашивает у `github.com`, не вышел ли релиз новее
вашей версии. Если вышел, под шапкой окна появляется плашка «Вышла версия 0.3.3»: «Что нового» открывает страницу релиза,
«Скачать» скачивает файл для вашей системы (на Windows `.exe`, на Mac `.dmg` под ваш чип), крестик прячет плашку до следующего
запуска. В настройках, в разделе «Обновления», видна текущая версия, кнопка **«Проверить обновление»**, пункт «Пропустить эту
версию» и переключатель автопроверки. Проверка тихая: нет связи с GitHub, ничего не показывается и работе не мешает.
Запрос раскрывает GitHub только обычный адрес вашего компьютера. Из исходников (не из собранного приложения) автопроверки нет.

**Установка в один клик (Windows).** На Windows вместо «Скачать» на плашке и в настройках кнопка **«Установить»**. Говорилка
скачивает файл только с `github.com` по HTTPS, сверяет размер и контрольную сумму SHA-256, которую публикует GitHub, и только
потом закрывается. Маленький скрипт подменяет файл по тому же пути (ярлыки и автозапуск остаются), запускает новую версию и
удаляет прежнюю копию. Если контрольной суммы нет или в папку с программой нельзя писать, установка откажется и предложит
скачать файл вручную. Установка не начнётся, пока идёт запись или расшифровка. На Mac Говорилка скачивает `.dmg`, проверяет подпись (тот же сертификат, что у установленной версии, поэтому выданные разрешения сохраняются), заменяет `.app` и открывается заново; из образа или из карантина заменить себя нельзя, сначала перетащите её в «Программы».

## Модели

В настройках, раздел «Запись», каталог моделей. Сначала видна выбранная, «Все модели» раскрывают остальные. У каждой
модели видно, зачем она, сколько весит, точность и скорость. Её можно скачать заранее кнопкой «Скачать» (с процентом)
и удалить корзиной, чтобы освободить место.

| Модель | Размер | Точность | Зачем |
|---|---|---|---|
| GigaAM v3 RNNT (по умолчанию) | 851 МБ | 92% | лучшая для русского, с пунктуацией |
| GigaAM v3 CTC | 844 МБ | 92% | почти та же, на треть быстрее |
| GigaAM v3 RNNT / CTC, экономные (int8) | 215 МБ | 92% | в 4 раза меньше, для ноутбуков с 8 ГБ памяти |
| T-one (Т-Банк) | 137 МБ | 93% | обучена на телефонных разговорах |
| GigaAM Multilingual | 564 МБ | 94% | русский, казахский, киргизский, узбекский, английский |
| NVIDIA Parakeet v3 | 639 МБ | 89% | 25 европейских языков, в том числе английский |
| NVIDIA FastConformer | 130 МБ | 88% | лёгкая русская, с пунктуацией |
| Vosk 0.54 | 69 МБ | 90% | маленькая и быстрая, без пунктуации |
| Vosk small | 25 МБ | 85% | для старых и слабых компьютеров |

Точность — сколько слов из 100 модель пишет верно на русской речи, по замерам
[onnx-asr](https://istupakov.github.io/onnx-asr/comparison/). У моделей с пунктуацией она чуть ниже из-за того, как её
считают, а читать их текст удобнее. Для экономных версий взята точность полной модели: свою стоит сверить на своих записях.

**Своя модель.** Кнопка «Своя модель…» под каталогом открывает выбор:

- **С Hugging Face:** адрес вида `автор/репозиторий`. Модель скачается один раз в папку моделей приложения. В репозитории
  должен быть `config.json` с полем `model_type` (так устроены репозитории onnx-asr). Можно взять облегчённую версию int8.
- **Папка на компьютере:** готовые файлы модели, ничего не копируется и не скачивается. Тип модели выбирается в списке
  или определяется по `config.json`. Под списком видно, какие файлы нужны для выбранного типа.

Говорилка понимает форматы ONNX: NeMo (FastConformer, Conformer CTC/RNNT, Parakeet TDT, Canary), Vosk и Kaldi (zipformer),
T-One, Whisper и GigaAM, в том числе дообученные. Перед выбором модель проверяется: Говорилка загружает её и прогоняет
через неё тишину. Не загрузилась, показывается причина (например, какого файла в папке не хватает), и прежняя модель
остаётся. Проверенная модель становится основной после «Сохранить».

**Память.** Модели занимают около гигабайта. Если запись не идёт, через 10 минут (в настройках: 5, 10, 30 минут или никогда)
Говорилка выгружает их: в трее остаётся около 60–200 МБ. Следующая запись начнётся на пару секунд позже.

## Для разработки

Интерфейс: PySide6 + QML (см. [docs/adr/0001-qt-ui.md](docs/adr/0001-qt-ui.md)). Сборка выросла на 50 МБ из-за Qt.

Запуск из исходников, Windows:

```powershell
install.bat
Govorilka.bat
```

Mac (нужны Python 3.12 с python.org и Xcode Command Line Tools; на Intel поставится onnxruntime 1.23.2):

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
mkdir -p bin && swiftc -O mac/audiotap.swift -o bin/govorilka-audiotap
.venv/bin/python -m govorilka
```

Тесты: `python -m pytest -q tests` (Qt работает без экрана, программная отрисовка). Самопроверки без окна, их же гоняет CI в собранных приложениях:

- `Govorilka --selftest tests/fixtures/speech_ru.wav` — файл через весь путь (декодер, детектор речи, распознавание, голоса, эхоподавление), результат в `selftest.txt`;
- `Govorilka --selftest-ui` — окна QML грузятся без ошибок и рисуют не пустоту, иконки на месте, результат в `selftest-ui.txt`.

Снимки интерфейса для проверки глазами: `python tools/shots.py <папка> [dark|light]`. Иконки пересобираются командой `python tools/make_icons.py` (нужен Pillow).

Сборка `.exe` и `.dmg` идёт в GitHub Actions ([release.yml](.github/workflows/release.yml)). Каждый push в `main` собирает обе версии и проверяет их на реальной модели. Тег `v*` дополнительно публикует релиз:

```bash
git tag v0.3.0 && git push origin v0.3.0
```

Структура `govorilka/`:

- `hotkeys.py` — горячая клавиша: распознавание комбинации, запись новой, опрос клавиш Windows и Mac;
- `autostart.py` — запуск при входе в систему (реестр Windows, LaunchAgent на Mac);
- `single_instance.py` — не даёт запустить вторую копию;
- `controller.py` — логика приложения без интерфейса: запись, пауза, отметки, файлы, горячая клавиша, отправка нейросети;
- `qt/` — интерфейс: `backend.py` (мост к QML: сигналы из потоков, слоты, свойства), `models.py` (лента транскрипта), `tray.py` (значок в трее и строке меню), `icons.py` (набор иконок из SVG), `app.py` (запуск);
- `qml/` — окна и компоненты: `Main.qml`, `SettingsWindow.qml`, `RadialMenu.qml`, `RecordingPill.qml`, `Theme.qml` (цвета, размеры, движение) и мелкие детали вроде `Bezel.qml` и `PillButton.qml`;
- `assets/` — иконка приложения (`.png`, `.ico`, `.icns`) и значки для трея;
- `audio.py` — выбирает захват звука под ОС;
- `audio_windows.py` — микрофон и loopback через WASAPI;
- `audio_mac.py` — микрофон и системный звук через помощника `mac/audiotap.swift` (AVAudioEngine и ScreenCaptureKit);
- `vad.py` — детектор речи Silero (нейросеть 2 МБ) и запасной по громкости;
- `segmenter.py` — нарезка звука на фразы по паузам, длинную фразу режет в самом тихом месте;
- `speakers.py` — отпечатки голосов (wespeaker), пересчёт голосов по ходу записи и после неё;
- `refine.py` — уточнение подписей после созвона, перенос имён;
- `voices.py` — память голосов знакомых (по желанию, локально);
- `models.py` — скачивание моделей с процентом;
- `engines.py` — все модели приложения;
- `updates.py`, `version.py` — проверка обновлений на GitHub и номер версии (его записывает сборка);
- `asr_models.py` — какие модели распознавания поддерживаются: каталог, int8, свои с Hugging Face и из папки;
- `filejob.py` — расшифровка аудио- и видеофайлов через PyAV;
- `win_devices.py` — выбранные в Windows устройства (Core Audio);
- `recognizer.py` — GigaAM через onnx-asr;
- `pipeline.py` — поток на каждый источник: звук → фразы → текст;
- `echo.py` — фильтр эха колонок;
- `session.py` — одна запись: устройства, потоки, автосохранение;
- `transcript.py` — реплики и Markdown;
- `claude_bridge.py` — запуск Claude Code в терминале;
- `ai.py` — какие нейросети поддерживаются, проверка страны, текст для чатов;
- `desktop_apps.py` — поиск и запуск настольных ChatGPT и Claude;
- `names.py` — имена собеседников из самого разговора;
- `selftest.py` — самопроверка собранного приложения;
- `app.py` — точка входа: журнал, самопроверки, запуск интерфейса.

Модели и настройки собранное приложение хранит в `%LOCALAPPDATA%\Govorilka` (Windows) или `~/Library/Application Support/Govorilka` (Mac). Там же лежит `govorilka.log`.
