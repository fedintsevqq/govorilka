## [0.3.3] - 2026-10-26

### Добавлено
- Диктовка в любое поле: зажали Ctrl + Alt, сказали, отпустили, и текст появился у курсора.
- Итоги созвона: вкладка «Итоги» с кратким содержанием, решениями, задачами и открытыми вопросами. Считает
  языковая модель на компьютере (Qwen3 4B, Qwen2.5 1.5B или YandexGPT 5 Lite).
- Подсказки в звонке: кнопка в шапке окна, ответы модели на компьютере или нейросети по вашему ключу API. Окно не
  попадает в демонстрацию экрана. Выключены по умолчанию.
- Каталог из десяти моделей распознавания с размером, точностью и скоростью каждой. Своя модель с Hugging Face или из папки.
- Обновление в один клик на Windows и Mac.
- Выделение текста мышью по всей ленте и копирование через Ctrl+C (⌘C).
- Установка одной командой для Windows и Mac.
- Правка текста отметок, окно «Что нового» после обновления, запуск при входе в систему включается при первой установке.
- Русская строка меню на Mac.

### Изменено
- Загрузка моделей докачивается с места обрыва, у каждой модели итогов есть запасной адрес, а список адресов
  обновляется с GitHub без нового выпуска. Загрузку можно отменить, нехватка места на диске видна сразу.
- Плашка «● Запись» по умолчанию выключена и не видна при демонстрации экрана.
- Пульт записи прокручивается, а не обрезается, если окно маленькое. Нейросети выбираются выпадающим списком.
- Лицензия проекта: MIT.

### Исправлено
- Mac: окно настроек падало через пару секунд после открытия. Причиной был фильтр событий на всё приложение.
- Mac: падения из-за опроса клавиатуры не из главного потока и из-за статуса разрешений.
- Итоги сохраняются в файл своего разговора, даже если началась новая запись. «Отменить» прерывает и долгий ответ модели.
- Испорченный файл настроек откладывается в копию и не сбрасывает автозапуск.
- Диктовка отменяется, если выключить её или поставить опрос клавиш на паузу посреди фразы.
- Обновление на Windows работает в папке со знаком «%» в пути.
- Безопасность: проверка сертификата при обновлении на Mac, ключ API не уходит при переадресации, локальная модель
  отвечает только с одноразовым ключом, ответы нейросетей показываются без ссылок и картинок.

## [0.3.2] - 2026-10-24

### Исправлено
- Mac: знакомство при первом запуске показывается, разрешения проще выдать и сбросить.
- Mac: круговое меню и плашка записи видны поверх полноэкранных приложений.

## [0.3.1] - 2026-10-24

### Исправлено
- Mac: при подключении или смене наушников (AirPods) пропадали микрофон и звук собеседников. Помощник захвата переподключается сам.

## [0.3.0] - 2026-10-24

### Добавлено
- Интерфейс на Qt: тёмная и светлая темы, круговое меню по горячей клавише, значок в трее и строке меню, плашка записи.
- Отправка разговора в установленные приложения ChatGPT и Claude, вставка в поле чата сама, в том числе после входа в аккаунт.
- Лента выбора нейросети, проверка страны, чтобы не получить блокировку аккаунта.
- Знакомство при первом запуске с тренировкой горячей клавиши.
- Надёжные подписи собеседников по ходу записи, имена из разговора, подсказки к кнопкам.

## [0.2.2] - 2026-10-23

### Добавлено
- Эхоподавление: колонки без наушников больше не дублируют слова собеседника в «Я».
- Поиск Claude Code, встроенного в Claude Desktop, на Windows и Mac.

### Изменено
- Быстрее распознавание, исправления горячей клавиши и запуска при входе в систему.

## [0.2.1] - 2026-10-23

### Исправлено
- Mac: отказ в доступе к звуку отличается от других сбоев помощника, есть кнопка сброса разрешений.

## [0.2.0] - 2026-10-23

### Добавлено
- Тихая запись по горячей клавише и автозапуск при входе в систему.

### Исправлено
- Mac: порт, который не даёт запустить вторую копию, освобождается надёжно.

## [0.1.1] - 2026-10-23

### Исправлено
- Читаемый текст транскрипта в тёмной теме.

## [0.1.0] - 2026-10-23

### Добавлено
- Первый выпуск: запись созвона в реальном времени, микрофон и звук компьютера отдельно, распознавание GigaAM,
  детектор речи Silero, разделение собеседников, расшифровка файлов, переключение устройств посреди звонка, сборки
  для Windows, Mac на Apple Silicon и Mac на Intel.
